Voici la feuille de route maîtresse et le plan d'intervention technique linéaire pour le déploiement opérationnel de **SuperBrain** ([sidinsearch/superbrain](https://github.com/sidinsearch/superbrain)) sur smartphone Android.

---

### Résultat final attendu

Obtenir un système fonctionnel de « deuxième cerveau » auto-hébergé composé de deux briques interconnectées :

1. **Un serveur Backend (Python / FastAPI)** opérationnel, hébergé sur une machine hôte (PC local, serveur domestique ou VPS cloud), configuré avec les clés d'API nécessaires (Gemini, Groq, OpenRouter) et les dépendances d'extraction (FFmpeg).
2. **Une application cliente Android** installée via fichier APK, connectée au backend par un jeton d'accès sécurisé (*Access Token*), capable d'intercepter les partages d'URL depuis n'importe quelle application (Instagram, YouTube, navigateurs web) pour les analyser, les résumer par IA et les stocker dans une base de données SQLite locale.

---

### Ressources nécessaires

#### 1. Hardware

* **Smartphone Android** : Android 10.0 ou version ultérieure.
* **Machine hôte (Backend)** : Un ordinateur (Windows, macOS ou Linux), un Raspberry Pi (Pi 4/5), ou un serveur privé virtuel (VPS / Cloud Run) connecté à Internet.

* **Python** : Version 3.10 ou supérieure.

### Plan d'intervention et de déploiement linéaire

#### Phase 1 : Obtention des clés d'API et préparation de la machine hôte

1. **Génération des clés d'API IA**
1. Accéder au portail [Google AI Studio](https://aistudio.google.com/), créer une clé API et la copier dans un bloc-notes temporaire sous la variable `GEMINI_API_KEY`.
2. Accéder à la [Console Groq](https://console.groq.com/), générer une clé API sous la variable `GROQ_API_KEY`.
3. *(Optionnel)* Accéder à [OpenRouter](https://openrouter.ai/) pour récupérer une clé `OPENROUTER_API_KEY`.


2. **Installation des prérequis système sur la machine hôte**
1. Installer Python 3.10+ depuis [Python.org](https://www.python.org/downloads/) en veillant à cocher l'option *« Add Python to PATH »*.
2. Installer Node.js 20+ depuis [Nodejs.org](https://nodejs.org/).
3. Installer FFmpeg depuis [FFmpeg.org](https://ffmpeg.org/download.html) et ajouter le dossier `bin` aux variables d'environnement système (`PATH`). Vérifier dans un terminal avec :
```bash
ffmpeg -version

```





---

#### Phase 2 : Déploiement et initialisation du Backend Python

*Note : Deux options de déploiement sont possibles. La **Méthode A (npm)** est privilégiée pour sa simplicité. La **Méthode B (Git/Python)** est adaptée aux déploiements personnalisés.*

##### Option A : Déploiement rapide via npm / npx (Recommandé)

3. **Exécution du serveur d'installation automatique**
1. Ouvrir un terminal sur la machine hôte et exécuter la commande suivante :
```bash
npx -y superbrain-server@latest

```


2. Suivre l'assistant d'installation interactif (*setup wizard*) s'affichant à l'écran.
3. Renseigner les clés d'API générées à la Phase 1 (`GEMINI_API_KEY`, `GROQ_API_KEY`).
4. *(Optionnel)* Définir les identifiants d'un compte Instagram secondaire pour la récupération des Reels privés ou restreints.
5. Retailler et noter soigneusement le jeton d'accès généré (*Access Token* / `X-API-Key`) affiché à la fin du script.



##### Option B : Déploiement manuel via Git et Python

4. **Clonage et configuration de l'environnement virtuel**
1. Cloner le dépôt et naviguer vers le dossier backend :
```bash
git clone https://github.com/sidinsearch/superbrain.git
cd superbrain/backend

```


2. Créer et activer un environnement virtuel Python :
* Linux/macOS :
```bash
python3 -m venv .venv
source .venv/bin/activate

```


* Windows :
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1

```




3. Installer les dépendances Python :
```bash
pip install -r requirements.txt

```


4. Dupliquer le fichier d'exemple d'environnement `.env.example` vers `.env` (ou éditer `config/.api_keys`) et y inscrire vos clés API (`GEMINI_API_KEY`, `GROQ_API_KEY`).
5. Lancer l'assistant d'initialisation et le serveur API :
```bash
python start.py

```


6. Noter l'URL d'écoute du serveur (par défaut `http://localhost:5000` ou `http://<IP_LOCALE>:5000`) ainsi que le jeton d'accès (*Access Token*).



---

#### Phase 3 : Exposition réseau du serveur Backend

5. **Détermination de l'adresse réseau d'accès**
* **Cas 1 : Utilisation sur le même réseau Wi-Fi local**
* Identifier l'adresse IP locale de la machine hôte (`ipconfig` sur Windows ou `ip a` / `ifconfig` sur Linux/macOS). Exemple : `192.168.1.50`.
* L'URL d'accès du serveur sera : `[http://192.168.1.50:5000](http://192.168.1.50:5000)`.


* **Cas 2 : Utilisation hors du domicile / réseau mobile (via Ngrok)**
1. Télécharger et installer [Ngrok](https://ngrok.com/).
2. Lier votre compte Ngrok avec la commande d'authentification fournie sur votre tableau de bord Ngrok.
3. Lancer le tunnel vers le port 5000 :
```bash
ngrok http 5000

```


4. Copier l'URL sécurisée générée par Ngrok (ex. `[https://xxxx-xx-xx.ngrok-free.app](https://xxxx-xx-xx.ngrok-free.app)`).





---

#### Phase 4 : Installation et configuration de l'application Android

6. **Téléchargement et installation du package APK**
1. Depuis le smartphone Android, accéder à la page des [Releases GitHub SuperBrain](https://www.google.com/search?q=https://github.com/sidinsearch/superbrain/releases).
2. Télécharger le fichier `superbrain.apk`.
3. Ouvrir le fichier `.apk` sur le téléphone et autoriser l'installation à partir de sources inconnues si le système le demande.


7. **Appairage de l'application mobile au serveur Backend**
1. Lancer l'application **SuperBrain** sur le smartphone.
2. Accéder à l'écran **Settings** (Paramètres).
3. Dans le champ **Backend URL**, saisir l'URL définie à la Phase 3 (ex. `[http://192.168.1.50:5000](http://192.168.1.50:5000)` ou l'URL HTTPS Ngrok).
4. Dans le champ **Access Token**, coller le jeton d'accès (`X-API-Key`) récupéré lors de l'initialisation du backend à la Phase 2.
5. Appuyer sur le bouton de test de connexion et vérifier le retour d'état HTTP `/health` (Statut : *OK*).



---

#### Phase 5 : Recette opérationnelle et validation End-to-End

8. **Test d'extraction d'un article Web**
1. Ouvrir un navigateur mobile (Chrome) sur une page d'article d'actualité.
2. Appuyer sur le bouton de partage Android, puis sélectionner **SuperBrain**.
3. Vérifier la réception de la notification de prise en charge et contrôler dans l'application que l'article est correctement résumé et catégorisé.


9. **Test d'extraction d'une vidéo YouTube**
1. Ouvrir l'application YouTube, sélectionner une vidéo et appuyer sur *Partager* -> **SuperBrain**.
2. Vérifier que Gemini analyse l'URL et extrait le titre, le résumé textuel et les mots-clés associés.


10. **Test d'extraction d'un Reel Instagram**
1. Ouvrir Instagram, sélectionner un Reel public et partager le lien vers **SuperBrain**.
2. Vérifier dans la fiche du post la transcription textuelle, l'analyse du contenu et l'identification de la piste musicale via Shazamio.
