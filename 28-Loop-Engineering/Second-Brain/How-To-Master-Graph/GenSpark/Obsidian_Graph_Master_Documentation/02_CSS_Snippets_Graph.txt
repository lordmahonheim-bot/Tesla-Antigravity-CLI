   02 — CSS SNIPPETS POUR LE GRAPH VIEW D'OBSIDIAN
   Fichier à copier dans .obsidian/snippets/graph-master.css
   Activation : Settings → Appearance → CSS snippets → toggle ON
════════════════════════════════════════════════════════════════════════════════

⚠ RAPPEL TECHNIQUE
  Le Graph View est rendu en WebGL (Pixi.js). Seule la propriété `color:`
  est lue par le "bridge" CSS → WebGL. `background-color`, `opacity`,
  `border`, etc. n'ont AUCUN effet sur les nœuds. Utiliser des hex/rgb.

────────────────────────────────────────────────────────────────────────────────
5) PANNEAU DE RÉGLAGES — apparence du menu Graph (non-WebGL)
   Ces snippets N'AGISSENT PAS sur le rendu du graph mais sur son UI.
────────────────────────────────────────────────────────────────────────────────

/* Rendre le panneau de réglages plus compact et translucide */
.graph-controls {
    background-color: rgba(0, 0, 0, 0.55) !important;
    backdrop-filter: blur(6px);
    border-radius: 10px;
    padding: 10px !important;
    font-size: 0.85em;
}

/* Personnaliser les sliders */
.graph-controls input[type="range"] {
    accent-color: #5dbcd2;
}

/* Cacher le bouton "Restore defaults" (attention: irréversible !) */
/* .graph-controls .clickable-icon[aria-label*="Restore"] { display: none; } */

────────────────────────────────────────────────────────────────────────────────
6) NŒUDS PAR TAG (via groupes en amont)
   RAPPEL : la coloration par TAG SPÉCIFIQUE se fait via l'interface
   Groups (recherche → couleur), PAS via CSS. Le CSS ne peut pas cibler
   un tag précis dans le WebGL. Utiliser les Groupes natifs.
────────────────────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────────────
7) MISE EN VALEUR DE LA VUE (couches non-WebGL)
────────────────────────────────────────────────────────────────────────────────

/* Fond dégradé subtil derrière le graph */
.graph-view.color-background {
    color: #0d1117;  /* le rendu appliquera cette couleur au fond WebGL */
}

/* Encadrer le graph dans l'onglet */
.workspace-leaf-content[data-type="graph"] .view-content {
    box-shadow: inset 0 0 40px rgba(0,0,0,0.4);
}

════════════════════════════════════════════════════════════════════════════════
UTILISATION
────────────────────────────────────────────────────────────────────────────────
  1. Créer un fichier .obsidian/snippets/graph-master.css dans votre vault.
  2. Copier UN SEUL des blocs (1 à 5) selon la palette voulue.
  3. Settings → Appearance → CSS snippets → activer graph-master.
  4. Rouvrir le Graph View.

RECOMMANDATION
  Ne combinez pas plusieurs palettes : les propriétés `color:` se
  surchargent selon la spécificité et l'ordre. Une palette à la fois.

TESTER SES COULEURS
  https://encycolorpedia.com/  (hex codes + suggestions harmoniques)
  https://coolors.co/           (générateur de palettes)
  https://colorbrewer2.org/     (palettes accessibles catégorielles)
