COMMENT UTILISER CETTE DOCUMENTATION
────────────────────────────────────────────────────────────────────────────────

  1. DÉBUTANT — Lire 01_Master (§1 à §6) puis appliquer 05_Checklist niveau 1.
  2. INTERMÉDIAIRE — Ajouter 02_CSS + 03_Filtres, tester les presets fournis.
  3. AVANCÉ — Installer les plugins de 04_Plugins, appliquer 05_Checklist
     niveau 3, itérer avec les métriques de Graph Analysis.
  4. MASTER — Combiner MOC + Breadcrumbs + Extended Graph + CSS custom,
     bookmarker plusieurs configurations, exporter en SVG/DOT.
