   03 — CHEATSHEET : FILTRES & GROUPES DU GRAPH VIEW
   Toute la syntaxe utilisable dans "Search files" et dans les Groupes
   (identique à la syntaxe de la recherche globale d'Obsidian)
════════════════════════════════════════════════════════════════════════════════

────────────────────────────────────────────────────────────────────────────────
A. OPÉRATEURS FONDAMENTAUX
────────────────────────────────────────────────────────────────────────────────

  mot                    → recherche plein-texte (fuzzy)
  "expression exacte"    → recherche littérale (case-insensitive)
  OR                     → union
  espace / AND           → intersection (implicite)
  -terme                 → NOT (exclusion)
  ( ... )                → groupement
  /regex/                → expression régulière

────────────────────────────────────────────────────────────────────────────────
B. PRÉFIXES SPÉCIALISÉS
────────────────────────────────────────────────────────────────────────────────

  file:NOM               → nom de fichier contient NOM
  path:CHEMIN            → chemin (dossier) contient CHEMIN
  content:TEXTE          → contenu (corps de note) contient TEXTE
  tag:#TAG               → note taguée #TAG
  line:(A B)             → A et B sur la MÊME LIGNE
  block:(A B)            → A et B dans le MÊME BLOC (paragraphe)
  section:(A B)          → A et B dans la MÊME SECTION (heading)
  task:                  → contient une tâche (- [ ] ou - [x])
  task-todo:MOT          → tâche non-cochée contenant MOT
  task-done:MOT          → tâche cochée contenant MOT
  property:CLE:VAL       → propriété YAML (frontmatter) — récent

────────────────────────────────────────────────────────────────────────────────
C. EXEMPLES PRÊTS À L'EMPLOI
────────────────────────────────────────────────────────────────────────────────

  ● Toutes les MOCs :
      tag:#moc

  ● Projets actifs (hors archive) :
      path:Projects/ -path:Projects/Archive/

  ● Union de deux domaines :
      path:home/ OR path:work/

  ● Zettels permanents en anglais :
      tag:#permanent tag:#lang-en

  ● Notes avec TODO ouvert :
      task-todo:

  ● Notes de journal 2026 :
      /^Journal\/2026-/

  ● Exclure les fichiers image inline :
      -/\.(png|jpe?g|svg|webp|gif)$/

  ● Toutes les notes d'auteur X :
      content:"Author:: X"

  ● Notes avec titre commençant par un ID Zettel (14 chiffres) :
      /^\d{14}/

  ● Notes littérature SAUF brouillons :
      tag:#literature -tag:#draft

  ● Notes créées récemment (via property YAML) :
      property:created:2026-07

────────────────────────────────────────────────────────────────────────────────
D. RECETTES DE GROUPES DE COULEURS
────────────────────────────────────────────────────────────────────────────────

RECETTE 1 — "Types LYT/Zettelkasten" (5 groupes)
  Groupe 1 : tag:#moc                    → ROUGE      (hubs)
  Groupe 2 : tag:#permanent              → VERT       (idées durables)
  Groupe 3 : tag:#literature             → BLEU       (sources)
  Groupe 4 : tag:#fleeting               → GRIS       (éphémères)
  Groupe 5 : tag:#project                → ORANGE     (opérationnel)

RECETTE 2 — "Domaines" (6 groupes)
  Groupe 1 : path:01-Health/             → VERT
  Groupe 2 : path:02-Career/             → BLEU
  Groupe 3 : path:03-Finance/            → OR
  Groupe 4 : path:04-Learning/           → VIOLET
  Groupe 5 : path:05-Relations/          → ROSE
  Groupe 6 : path:06-Creative/           → ORANGE

RECETTE 3 — "Maturité" (3 groupes)
  Groupe 1 : tag:#evergreen              → VERT FONCÉ
  Groupe 2 : tag:#budding                → VERT MOYEN
  Groupe 3 : tag:#seedling               → VERT CLAIR

RECETTE 4 — "Diagnostic"
  Groupe 1 : task-todo:                  → ROUGE      (à traiter)
  Groupe 2 : tag:#review                 → JAUNE      (à réviser)
  Groupe 3 : -[[]]                       → GRIS       (orphelines, approx.)

────────────────────────────────────────────────────────────────────────────────
E. PRIORITÉ DES GROUPES
────────────────────────────────────────────────────────────────────────────────

  → Le PREMIER groupe qui matche s'applique.
  → Placer en haut de la liste les groupes les PLUS SPÉCIFIQUES.
  → Un nœud n'a qu'UNE couleur de groupe à la fois.

  Exemple d'ORDRE optimal :
     1. tag:#moc                 (le plus spécifique)
     2. tag:#permanent tag:#urgent
     3. tag:#permanent
     4. tag:#literature
     5. path:Projects/

────────────────────────────────────────────────────────────────────────────────
F. PIÈGES FRÉQUENTS
────────────────────────────────────────────────────────────────────────────────

  ✗ tag:coworker           → NE FONCTIONNE PAS (manque le #)
  ✓ tag:#coworker

  ✗ path:home              → matche aussi "home-office" etc.
  ✓ path:home/             → matche uniquement le dossier "home"

  ✗ tag:#idea OR #draft    → mal formé
  ✓ tag:#idea OR tag:#draft

  ✗ -path:Archive          → matche aussi "MyArchive"
  ✓ -path:Archive/
