### 1. Documentation officielle Obsidian (obsidian.md/fr/help/syntax)
- Syntaxe Markdown de base: paragraphes, sauts de ligne, entêtes, gras/italique/surlignage
- Liens internes et externes

- Notes de bas de page, commentaires
- Paramètre "Sauts de ligne stricts"

### 2. Guide de style officiel (obsidian.md/fr/help/style-guide)
- Terminologie: "note" pour fichier Markdown, "fichier" pour autres extensions
- Noms de produits: "Obsidian Publish", "Obsidian Sync"
- Interface: **gras** pour boutons, "sélectionnez" au lieu de "cliquez sur"
- Directions: "supérieur gauche" pas "haut gauche"
- Instruction en impératif
- Casse de phrase pour entêtes
- Encadrés: [!tip]-, [!info]+, [!warning]+, [!example]-
- Raccourcis clavier: Ctrl+Z (Windows) ou Command+Z (macOS)
- Séparer les blocs Markdown par des sauts de ligne

### 4. Optimike - Markdown dans Obsidian
- Markdown = langage de balisage léger, fichiers .md stockés localement
- Modulaire, interopérable, contrôle total
- Liens internes [[Nom de la note]] = cœur du système
- Liens externes [texte](url)
- Images: ![[nom-fichier.jpg]]
- Tableaux Markdown
- Blocs de code avec accents graves
- Callouts: > [!note] Titre
- Tâches: - [ ] et - [x]
- Bonnes pratiques: nommage rigoureux, hiérarchisation, tags, liens bidirectionnels
- Méthode PARA vs liens: privilégier les liens
- Structure de dossiers simple pour débuter

### 7. Reddit - Limitations Markdown pour écriture académique
- Pandoc ajoute complexité
- Incompatibilité avec Zotero addons pour Word
- Fichiers Markdown ne contiennent pas les citations rendues
- Utiliser Markdown pour premier jet, puis Word/Writer pour polishing
- Mode distraction-free vs Word: similaire
