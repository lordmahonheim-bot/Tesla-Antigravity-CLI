### 1. Audit & Analyse Critique

#### ✅ Les points forts
*   **Idempotence :** L'utilisation de balises HTML (`<!-- SESSION: ID -->`) est excellente pour éviter les doublons.
*   **Automatisation :** L'ancrage dans `AGENTS.md` crée un réflexe opérationnel pour l'IA.
*   **Source de vérité :** L'extraction depuis le `.jsonl` natif garantit l'intégrité des données.

#### ⚠️ Les points faibles (Risques)
*   **L'effet "Mur de Texte" :** À terme, `SESSION_TRANSCRIPTS.md` deviendra massif. L'IA aura du mal à retrouver une information précise sans consommer tout son contexte (tokens).
*   **Manque de Structuration :** Une transcription linéaire est chronologique, mais pas thématique. On ne peut pas "interroger" le fichier efficacement.
*   **Performance I/O :** Réécrire un fichier Markdown complet pour mettre à jour un bloc de session devient lent quand le fichier atteint plusieurs mégaoctets.
