## 📋 Protocole d'Utilisation

### Ouvrir un chantier
1. Mahonheim dit : *"J'ouvre un chantier [NOM]"*
2. Tesla pose 2-3 questions de cadrage rapides
3. Tesla crée : `[NOM-DU-CHANTIER]_v1.0_YYYY-MM-DD.md`
4. Tesla met à jour ce fichier INDEX.md
5. Tesla met à jour `memory/PROJECT_STATE.md` (résumé hybride)
6. Tesla indexe le fichier dans Alexandria (FTS5)

### Archiver un chantier
1. Mahonheim valide la clôture du chantier
2. Tesla vérifie les critères de clôture (DoD)
3. ⚠️ Si des enfants ne sont pas terminés : avertissement émis (pas de blocage)
4. Tesla complète la section "Signature & Horodatage de Clôture" du cahier de charges
5. Tesla déplace le fichier dans `Archivage-de-Chantiers/`
6. Tesla met à jour ce fichier INDEX.md
7. Tesla met à jour `memory/PROJECT_STATE.md`
