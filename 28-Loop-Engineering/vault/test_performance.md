# Fiche de Test Performance d'Alexandria
Ce fichier est utilisé pour évaluer le coût d'inférence vectorielle sur la machine locale MIDGARD.
Avec une enveloppe RAM de 8 Go, l'inférence CPU du modèle all-MiniLM-L6-v2 doit être la plus sobre possible.
L'indexation incrémentale permet d'ignorer immédiatement le traitement sémantique si aucun changement n'est détecté.
