## 1. Diagnostic (Why?)
The `@lordmahonheim-bot` ecosystem requires a robust infrastructure for the orchestration, validation, and governance of its operations. The Tesla Governance Gateway (TGG) ensures compliance, auditability, and control of execution and deployment flows according to the directives of the Vigilum Codex.

## 2. Architecture & Features (What?)
This repository contains the initial version (MVP 27) of the governance tools:
- **Policy Engine (`policy_engine.sh`)**: Validation of security and deployment rules.
- **Capability Registry (`capability_registry.json`)**: Formal definition of agent and subsystem rights.
- **Security Hooks (`pre-commit`)**: Automated quality control.
- **Agent Orchestration (`agents/`)**: Autonomous fleet management modules.
