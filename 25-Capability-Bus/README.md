# MVP 25 - Capability Bus

## 1. Diagnostics
Necessity to modularize system capabilities via a bus capable of loading and executing plugins based on events.

## 2. Description
The Capability Bus allows the execution of plugins (capabilities) listed in `registry.json`.

## 3. Proof
- Contains the `capability_dispatcher.sh`, `capability_resolver.sh`, and configuration files within `tools/capability_bus/`.
